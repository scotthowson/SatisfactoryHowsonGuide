# SatisfactoryHowson guides

The guides for our modded Satisfactory server, as a website: <https://scotthowson.github.io/SatisfactoryHowsonGuide/>

- Rocky Desert Works: where to base and what to build, on a map you can drag
- Builder's Handbook: first builds, basic to advanced
- Game plan, pacing, mod guide, mod list, and the install guides

These files are copied from the `docs` folder of a private repository that also holds the mod packs. Do not edit them here; they are overwritten on the next copy.
